# 文学 AI 痕迹四角度复核

风险分是启发式文本风险，不是真实 AI 参与比例或作者身份鉴定。

完整阅读 `references/review-schema.md` 后执行。

## 隔离四个角色

1. **style_fidelity**：只判断改稿是否仍符合已确认画像，是否出现统一、平滑、可预测的替代腔。
2. **ai_language**：只检查模板转折、解释性回声、机械节奏、伪精确、过度工整和公式化结尾。
3. **narrative_integrity**：检查剧情与情感变化，同时判断编辑是否因追求自然而制造新的 AI 式动机、对白或象征。
4. **cold_reader**：不看其他评分，以普通文学读者身份盲读，指出哪里像生成文本、哪里仍有作者气息。

有子 Agent 时分别派发四个隔离任务；没有时串行执行四遍。每个角色只能看到原稿、改稿、画像、内容锁定清单和自己的角色说明，不得看到其他角色的评分。

## 评分纪律

- 每个角色输出 `0–100` 风险分和 `0–100` 置信度。
- 每项风险必须给出具体位置和短证据；没有证据不得扣分。
- 个人不喜欢某种文风不能作为 AI 证据。
- 常见词单次出现、句子通顺、主题伤感、短句或比喻本身不能证明 AI。
- `narrative_integrity` 额外输出 `integrity_pass` 和实质问题列表。

把四份 JSON 保存后运行 `scripts/aggregate_reviews.py`。四分极差超过20时启动第五个 `arbitrator` 隔离复核；仲裁者只能看到四份证据和文章，不看到设计目标，输出独立分数。

## 迭代与停止

同时满足以下条件才通过：

- 汇总风险分不高于20；
- 确定性完整性检查通过；
- 语义完整性审计通过；
- 剧情情感角色没有实质问题。

不通过时把各角色证据合并成去重后的修改清单，只返修证据指向的片段。最多三轮。继续降分会破坏内容时停止并如实标记未达标。
