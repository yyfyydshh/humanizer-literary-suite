# 作者文风画像格式

按以下顺序输出。未知项写“证据不足”，不要补造。

```markdown
---
profile_id: <小写字母数字和连字符>
mode: stable | single
sample_count: <整数>
confidence: high | medium | low
confirmed: false
created_at: <ISO 8601 时间>
---

# 作者文风画像：<显示名称>

## 样本边界
- 样本数量与题材范围：
- 可能的污染或偏差：

## 稳定文风
- 叙述视角与距离：
- 句段节奏：
- 用词与对白：
- 场景、心理与留白：
- 物件、感官、比喻与数字：
- 情绪温度与曲线：
- 开头、转场、高潮与结尾：

## 必须保护
- <特征 + 功能 + 证据>

## 可调整
- <特征 + 安全调整范围>

## AI重叠风险
- <表面信号 + 保留条件 + 修改条件>

## 本次修改方向
1. <只写有证据的方向>

## 禁止改变
- 剧情、人物关系、叙述视角、时间线、情感曲线、核心意象、结局和创作立场。

## 证据
- <不超过40字的短句或位置说明>
```

恒稳模式在用户确认后把 `confirmed` 改为 `true`。单篇模式展示同样结构，但不保存。
